## Structure de dossier recommandée pour lancer le projet

```
peche-lozere/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── images/
│   │   ├── hero-riviere.jpg
│   │   ├── lac-naussac.jpg
│   │   ├── lac-villefort.jpg
│   │   ├── lac-charpal.jpg
│   │   ├── truite-fario.jpg
│   │   ├── truite-arc-en-ciel.jpg
│   │   ├── brochet.jpg
│   │   ├── sandre.jpg
│   │   ├── guide-peche-mouche.jpg
│   │   └── paysage-cevennes.jpg
│   └── icons/
├── contenu-site-peche-lozere.md   (textes et données)
└── prompt-site-peche-lozere.md    (prompt Claude)
```

Crée ce dossier sur ton ordinateur, place les images téléchargées dans `assets/images/` avec ces noms, puis donne le prompt à Claude en lui précisant les noms de fichiers exacts pour qu'il les référence correctement dans le code.
